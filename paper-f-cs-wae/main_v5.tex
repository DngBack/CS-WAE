\begin{abstract}
% ============================================================
Factorized generative models regularize a style latent $\zs$ toward a fixed
prior using a marginal statistic, $q(\zs)\approx\mathcal N(0,I)$, and treat
this as a certificate that $\zs$ is class-invariant. We show the certificate
is invalid: matching the marginal places no constraint on the class
conditionals $q(\zs\mid y{=}k)$, so $\zs$ can be exactly Gaussian in
aggregate while remaining maximally informative about the class label $y$.
We call the resulting failure \emph{conditional style leakage} and give a
diagnostic for it based on inter-class style separation, linear probing, and
HSIC. Across four unsupervised baselines (VAE, WAE-MMD, $\beta$-TCVAE,
FactorVAE) and a case-study model, \ours{}, every model with near-zero
global MMD nonetheless allows a linear probe to recover $y$ from $\zs$ with
$74$--$100\%$ accuracy (chance $10\%$); on MNIST, \ours{} reaches $99.15\%$
clustering accuracy while class-conditional generation succeeds only $15\%$
of the time under the sampling procedure that marginal matching is supposed
to license. We test two remedies. A supervised per-class style MMD
substantially reduces, but does not eliminate, the leakage, at a clustering
cost that is dataset-dependent rather than a fixed price of the fix. A
post-hoc class-conditional style prior fully repairs MNIST generation
without retraining, but only partially repairs CIFAR-10, so a remedy
validated on one dataset does not automatically generalize to another. The
broader point is methodological: no divergence computed on $q(\zs)$ alone
can certify $\zs\perp y$, and factorized generative models that report only
marginal statistics have not actually verified the property they claim.
\end{abstract}

% ============================================================
\section{Introduction}
\label{sec:intro}
% ============================================================

Matching the aggregate style posterior to a Gaussian prior is a statement
about a marginal distribution; class-invariant style is a statement about a
family of conditional distributions. The two are not the same claim, and
satisfying the first does not satisfy the second: $q(\zs)$ can be exactly
$\mathcal N(0,I)$ while each $q(\zs\mid y{=}k)$ occupies a different region
of latent space, so long as those regions average out to the right
aggregate shape. A regularizer that only ever looks at $q(\zs)$ has no way
to see this, and therefore no way to prevent it.

\paragraph{Where this bites.}
Consider a toy version of the standard factorized setup: a semantic
variable $\zc$ carries class identity, a style variable $\zs$ is meant to
carry everything else, and $\zs$ is trained to satisfy
$q(\zs)\approx\mathcal N(0,I)$. During training, the decoder only ever sees
$(\zc,\zs)$ pairs drawn from the same image, so if $q(\zs\mid y{=}k)$
happens to differ across classes---which nothing in the training objective
prevents---the decoder is free to learn class-specific interactions between
$\zc$ and $\zs$. At generation time, a class prior supplies $\zc$ for class
$k$ while $\zs$ is drawn from the \emph{marginal}, $\mathcal N(0,I)$, which
averages over all classes. The resulting pair $(\zc,\zs)$ is one the decoder
never saw during training, and its output is unconstrained by anything the
model learned. We call this failure \emph{conditional style leakage}.

\paragraph{Why the usual metrics do not catch it.}
The failure is silent precisely because it is invisible to the metrics a
practitioner would normally check. Reconstruction quality is measured on
the posterior manifold -- $\zs$ inferred from a real image -- where the
class-specific interaction the decoder learned is exactly the one being
exercised, so reconstruction looks fine. Global MMD is a marginal statistic
by definition and, as above, is compatible with arbitrary conditional
structure. Clustering accuracy depends only on the semantic variable $\zc$
and says nothing about $\zs$ at all. A model can therefore score well on
every diagnostic a typical evaluation protocol reports and still fail
completely at class-conditional generation, which is the one capability the
factorization exists to provide.

\paragraph{A diagnostic, not just an example.}
Because the failure does not show up in standard metrics, detecting it
requires measurements taken directly on the conditional structure of $\zs$:
we use inter-class style separation $\Delta_{\mathrm{inter}}$, linear
probing accuracy of $y$ from $\zs$, and HSIC$(\zs,y)$
(Section~\ref{sec:diagnostics}), alongside the marginal MMD that current
practice already reports. A model with near-zero MMD but large
$\Delta_{\mathrm{inter}}$, elevated linear-probe accuracy, or non-zero HSIC
is leaking class information through a channel that was supposed to be
class-invariant.

\paragraph{What we find.}
Applying this diagnostic across five model families on MNIST, every model
with near-zero global MMD still allows a linear probe to recover the class
label from $\zs$ with $74$--$100\%$ accuracy against a $10\%$ chance rate
(Section~\ref{sec:cross-model}); this includes $\beta$-TCVAE and FactorVAE,
which are explicitly designed to penalize latent dependence. As a
concentrated case study, we instantiate \ours{} (Factorized
Class-Structured Spherical Cauchy Wasserstein Auto-Encoder), a model that
separates a hyperspherical semantic variable from a Euclidean style
variable; without any conditional regularization it reaches $99.15\%$
clustering accuracy on MNIST while class-conditional generation succeeds
only $15\%$ of the time. We then test two remedies -- a supervised
per-class style MMD applied at training time, and a post-hoc
class-conditional style prior applied at sampling time -- and report where
each helps, where it does not fully fix the problem, and where a fix
validated on MNIST fails to transfer to CIFAR-10
(Section~\ref{sec:cifar-sampling}).

\paragraph{Scope.}
We use \ours{} to exhibit and repair the failure, not to argue it is a
better model than the baselines it is compared against: the cross-model
comparison in Section~\ref{sec:cross-model} does not control for encoder
capacity or training budget, the CIFAR-10 baseline comparison in
Section~\ref{sec:cifar10-setup} is single-seed, and the proposed per-class
style MMD is a supervised, label-guided regularizer, not an unsupervised
disentanglement method. These scope limits are stated where they arise and
collected in Section~\ref{sec:limitations}.

\paragraph{Contributions.}
Our contributions are fourfold, and each answers a question the previous
one raises. First, we formalize the gap between marginal matching and
conditional independence and prove it is unavoidable for any aggregate
divergence, not a defect of a particular loss function
(Proposition~\ref{prop:marginal-not-sufficient}). This raises an obvious
follow-up: is the gap only a theoretical curiosity, or does it bite in
practice? Second, we build a lightweight diagnostic and measure it across
five model families, showing the leakage is not only real but, for three of
the five, invisible to a naive 2D projection of the latent
(Section~\ref{sec:cross-model}, Appendix~\ref{app:tsne}); we go beyond this
correlational evidence with a causal latent-swap intervention and the full
per-class/pairwise conditional-MMD structure behind $\Delta_{\mathrm{inter}}$
(Section~\ref{sec:swap}), showing the decoder does not merely have access
to leaked class information but measurably conditions on it, and that this
dependence itself shifts toward the semantic variable once the remedy is
applied. Given that the failure is real, the natural question is whether it
is fixable. Third, we propose per-class style MMD and show it substantially
reduces, but does not eliminate, leakage, at a clustering cost that is
dataset-dependent rather than uniform (Section~\ref{sec:method}); a
six-point sweep over $\delta$ (Section~\ref{sec:tradeoff}) confirms leakage
reduction is smooth in $\delta$ on both datasets, while showing clustering
cost is noisier across $\delta$ than the original two-point comparison
could reveal. Finally, because a fix validated
on one dataset is not a fix validated in general, we test whether the same
remedy transfers: the class-conditional sampling recipe that is fully
effective on MNIST only partially repairs CIFAR-10, a limitation invisible
from the MNIST results alone (Section~\ref{sec:cifar-sampling}). We report
this negative transfer result rather than omit it, since it constrains how
far the proposed fix can be trusted to generalize.

\section{Related Work}
% ============================================================

We organize prior work around a single question: does the method's training
or evaluation protocol certify conditional style invariance, $\zs\perp y$,
or only a marginal or joint statistic that is compatible with $\zs\not\perp
y$?

\paragraph{Variational and Wasserstein auto-encoders.}
VAEs~\citep{kingma2013autoencoding} impose a per-example KL penalty toward a
fixed Gaussian prior; WAEs~\citep{tolstikhin2017wasserstein} relax this to a
divergence between the \emph{aggregated} posterior and the prior, computed
with kernel two-sample tests~\citep{gretton2012kernel} or projected
distances~\citep{kolouri2018sliced}. All of these regularize $q(\zs)$ or a
per-example KL that, once aggregated over a labeled dataset, is again a
statement about $q(\zs)$; none of them evaluates $q(\zs\mid y)$, so none
certifies conditional invariance even when the marginal fit is good.

\paragraph{Disentanglement and total correlation.}
$\beta$-VAE~\citep{higgins2017beta} increases the KL weight to encourage
disentangled factors; $\beta$-TCVAE~\citep{chen2018isolating} and
FactorVAE~\citep{kim2018disentangling} isolate and penalize the total
correlation between latent dimensions directly. These methods get closer to
our concern, since total correlation is a joint-distribution statistic
rather than a purely marginal one, but the joint they penalize is over
\emph{latent dimensions}, not over the latent and the label. Table
\ref{tab:cross-model} shows both still leak: $\beta$-TCVAE and FactorVAE
have among the lowest global MMD in our comparison, yet a linear probe
recovers the class label from their style latent at $73.9\%$ and $75.9\%$
accuracy respectively, far above the $10\%$ chance rate.

\paragraph{Conditional and semi-supervised generative models.}
Semi-supervised VAEs~\citep{kingma2014semi} and
CVAE~\citep{sohn2015learning} condition generation on the label directly,
which sidesteps needing $\zc$ to encode class identity on its own, but
neither checks whether the \emph{residual} latent still carries label
information after conditioning. StyleGAN~\citep{karras2019style} factorizes
coarse structure from fine style via a mapping network in a
class-unconditional regime, so the question does not arise there in the
same form. Our setting requires both a class-conditional generator and a
label-free clustering signal from the same model, which is what makes
residual leakage in $\zs$ consequential rather than incidental.

\paragraph{Deep generative clustering.}
DEC~\citep{xie2015unsupervised}, IDEC~\citep{guo2017improved}, and
VaDE~\citep{jiang2016variational} evaluate almost exclusively via
ACC/NMI/ARI on the semantic or cluster-assignment variable. This protocol
cannot see conditional style leakage by construction, since it never
inspects $\zs$: our MNIST case study makes this concrete, reaching
$99.15\%$ clustering accuracy (Section~\ref{sec:cross-model-baseline}) on
exactly the checkpoint whose class-conditional generation succeeds only
$15\%$ of the time (Section~\ref{sec:exp2}).

\paragraph{Hyperspherical latent variables.}
S-VAE~\citep{davidson2018hyperspherical} replaces the Gaussian posterior
with a von Mises-Fisher distribution; Spherical Cauchy
VAEs~\citep{sablica2025hyperspherical} give a heavier-tailed alternative
with a M\"obius-transform reparameterization. We use the latter for the
semantic variable in our case-study model (Section~\ref{sec:instantiation}).
This choice of geometry is an implementation detail of the case study, not
a claim about the leakage problem, which is defined independently of how
$\zc$ is parameterized.

\section{The Conditional Style Leakage Problem}
\label{sec:phenomenon}
% ============================================================

\subsection{Setting and Notation}

Let $\mathcal{D}=\{(x_i,y_i)\}_{i=1}^n$ be a labeled dataset with $K$
classes. A factorized model encodes each input into a semantic variable
$\zc$ and a style variable $\zs$. The style variable is regularized by
\begin{equation}
  \mathcal{L}_{\mathrm{style}} = D\!\bigl(q(\zs),\;\mathcal{N}(0,I)\bigr),
  \label{eq:generic-style-reg}
\end{equation}
where $D$ is any aggregate divergence and $q(\zs)=\mathbb{E}_y[q(\zs\mid y)]$.
Class-conditional generation samples $\zs\sim\mathcal{N}(0,I)$ independently
of $\zc$.

\subsection{Formal Gap}
\label{sec:formal-gap}

\begin{proposition}[Marginal matching does not certify conditional independence]
\label{prop:marginal-not-sufficient}
Let $\zs\sim\mathcal N(0,I)$ on $\R^{d_s}$, and let $\{A_k\}_{k=1}^K$ be any
measurable partition of $\R^{d_s}$ with $P(\zs\in A_k)=1/K$ for each $k$
(such a partition always exists, e.g.\ via level sets of a continuous
statistic of $\zs$). Define the label $y$ as the deterministic function
$y=k \iff \zs\in A_k$. Then:
\begin{enumerate}[leftmargin=*,topsep=1pt,itemsep=1pt]
  \item[(i)] the marginal is unchanged, $q(\zs)=\mathcal N(0,I)$ exactly, so
        $D(q(\zs),\mathcal N(0,I))=0$ for \emph{every} divergence $D$; and
  \item[(ii)] $I(\zs;y)=H(y)=\log K$, the maximum mutual information
        achievable between $\zs$ and a $K$-ary label.
\end{enumerate}
\end{proposition}

\begin{proof}
(i) $y$ is defined post hoc as a measurable function of $\zs$; the
distribution of $\zs$ itself is never altered, so $q(\zs)=\mathcal N(0,I)$
holds exactly and every divergence to $\mathcal N(0,I)$, aggregate MMD
included, is identically zero. (ii) Since $y$ is a deterministic function of
$\zs$, $H(y\mid\zs)=0$, so $I(\zs;y)=H(y)-H(y\mid\zs)=H(y)$. By construction
$P(y=k)=1/K$ for all $k$, so $H(y)=\log K$, which is also the maximum
possible entropy -- and hence the maximum possible mutual information with
any other variable -- for a $K$-ary label.
\end{proof}

\begin{remark}
The construction is deliberately adversarial: $\{A_k\}$ need not resemble
anything a trained decoder would produce, and $q(\zs\mid y{=}k)$ here is
$\zs$ restricted to $A_k$ and renormalized, not a smooth family with
class-specific means. That is the point -- it shows that \emph{no}
divergence computed on $q(\zs)$ alone, MMD or otherwise, can rule out $\zs$
being maximally class-informative, regardless of how the dependence is
structured geometrically. Appendix~\ref{app:proof} gives a smoother,
empirically motivated construction with class-specific Gaussian
conditionals that connects the same impossibility result to the
finite-sample $\Delta_{\mathrm{inter}}$ statistic we use as a diagnostic
below; that construction is intuition for why $\Delta_{\mathrm{inter}}$ is a
reasonable statistic to track, not an alternative proof.
\end{remark}

\subsection{The Decoder Amplification Mechanism}
\label{sec:mechanism}

During training the decoder receives $(\zc,\zs)$ pairs from the same image;
both encode $y$ implicitly, $\zs$ because $q(\zs\mid y{=}k)$ is not
class-invariant. At generation time $\zc\sim p(\zc\mid y{=}k)$ encodes a
specific class while $\zs\sim\mathcal{N}(0,I)$ averages over all classes,
producing a cross-class pair never seen in training. Severity depends on how
class-structured $q(\zs\mid y)$ becomes: visually uniform classes (MNIST
digits) force more class information into $\zs$, amplifying the failure;
high-diversity classes (CIFAR-10) leave more class-neutral variation in
$\zs$. Section~\ref{sec:exp4} tests this prediction directly.

\subsection{Diagnostic Metrics}
\label{sec:diagnostics}

\paragraph{Global MMD} $\MMD^2(q(\zs),\mathcal{N}(0,I))$: near zero signals
only that marginal matching succeeded.

\paragraph{Inter-class style separation}
$\Delta_{\mathrm{inter}}=\frac{1}{\binom{K}{2}}\sum_{j<k}\|\bar\mus^{(j)}-\bar\mus^{(k)}\|_2$,
$\bar\mus^{(k)}=\mathbb{E}[\mus\mid y{=}k]$: large values indicate
class-dependent style means despite small global MMD. This is a
finite-sample, mean-separation statistic; it is a convenient, easily
computed symptom of conditional dependence, not what
Proposition~\ref{prop:marginal-not-sufficient} is about. That proposition
concerns statistical dependence in general (formalized as mutual
information) and holds even when class-conditional means coincide, so long
as higher-order structure differs.

\paragraph{Linear probing accuracy $\mathrm{LP}(\zs\to y)$}: accuracy of a
linear classifier predicting $y$ from $\zs$; well above chance $1/K$
confirms recoverable class information.

\paragraph{HSIC$(\zs,y)$}: kernel-based dependence
measure~\citep{gretton2005measuring}; non-zero indicates $\zs\not\perp y$
regardless of marginal shape.

A model with near-zero global MMD but large $\Delta_{\mathrm{inter}}$,
elevated LP, or non-zero HSIC is exhibiting conditional style leakage.

\section{Method}
\label{sec:method}
% ============================================================

\subsection{Problem Setting: Label-Guided Generative Clustering}

Given labeled images $\mathcal{D}=\{(x_i,y_i)\}_{i=1}^n$ with $K$ classes,
we want (1) reconstruction that preserves visual content, (2) clustering
that recovers class structure from semantic codes without using labels at
evaluation time, and (3) class-conditional generation that produces
class-consistent images from class priors.

\subsection{General Remedy: Per-Class Style MMD}
\label{sec:general-remedy}

The remedy we propose is architecture-agnostic and applies to any
factorized model with access to labels at training time. The standard,
insufficient regularizer matches the marginal:
\begin{equation}
  \mathcal{L}_{\mathrm{style}} = \MMD_{\mathrm{RBF}}\!\bigl(\{\zs^i\}_{i=1}^b,\,\{\varepsilon_j\}_{j=1}^b\bigr),
  \quad \varepsilon_j\sim\mathcal N(0,I).
  \label{eq:style-mmd}
\end{equation}
Our proposed fix instead matches each class conditional independently:
\begin{equation}
  \mathcal{L}_{\mathrm{style\text{-}cls}} = \frac{1}{K}\sum_{k=1}^{K}
    \MMD_{\mathrm{RBF}}\!\bigl(\{\zs^i:y_i{=}k\},\{\varepsilon_j\}_{|y_i=k|}\bigr).
  \label{eq:style-cls-mmd}
\end{equation}
Where Eq.~\ref{eq:style-mmd} has zero gradient incentive to reduce
inter-class separation -- the mixture can match $\mathcal N(0,I)$ while
every conditional remains class-structured
(Proposition~\ref{prop:marginal-not-sufficient}) -- Eq.~\ref{eq:style-cls-mmd}
penalizes exactly that failure mode, by construction. Nothing about this
term is specific to hyperspherical semantic variables, ResNet encoders, or
any other choice made in the case-study instantiation of
Section~\ref{sec:instantiation}: it requires only a labeled batch and a
style latent to regularize.

\paragraph{Scope of supervision.}
Because $\mathcal{L}_{\mathrm{style\text{-}cls}}$ is computed per class, it
requires labels at training time and is therefore a label-guided,
supervised regularizer, not an unsupervised disentanglement method in the
sense of $\beta$-TCVAE or FactorVAE. This is a different resource
assumption than the four unsupervised baselines in
Section~\ref{sec:cross-model}, and we do not present the comparison between
them as a like-for-like ablation of \emph{how} to achieve independence, only
as evidence that both unsupervised and supervised approaches leave
measurable leakage. The \emph{diagnostic} of Section~\ref{sec:diagnostics},
by contrast, requires only a labeled evaluation set and can be applied
post hoc to any trained model regardless of how it was supervised, which is
what makes it usable to audit the four unsupervised baselines in the first
place.

\subsection{Case-Study Instantiation: \ours{}}
\label{sec:instantiation}

To test the diagnostic and the remedy on a concrete model, we use \ours{}
(Factorized Class-Structured Spherical Cauchy Wasserstein Auto-Encoder),
which separates the latent into a hyperspherical semantic variable
$\zc\in\Sph^{d_c-1}$, aligned to class-conditional Spherical Cauchy priors
via a M\"obius reparameterization~\citep{sablica2025hyperspherical}, and a
Euclidean style variable $\zs\in\R^{d_s}$ regularized by
Eqs.~\ref{eq:style-mmd}--\ref{eq:style-cls-mmd}. A shared ResNet-18
backbone feeds two heads producing $(\muc,\rho_c,\mus,\log\sigma_s^2)$;
$\zc$ and $\zs$ are concatenated and decoded by a residual upsampling
network. Full architectural detail is in Appendix~\ref{app:arch}. The total
training objective additionally includes a supervised semantic MMD toward
the class prior ($\mathcal{L}_{\mathrm{class}}$), an aggregated semantic MMD
($\mathcal{L}_{\mathrm{agg}}$), and an auxiliary classification loss on
$\muc$ ($\mathcal{L}_{\mathrm{cls}}$) that prevents semantic collapse; these
terms shape $\zc$ for clustering and are not part of the style-leakage
remedy itself. Coefficients are ramped over a four-phase, 300-epoch
curriculum in which per-class style regularization begins in phase B,
before the decoder has had a chance to learn class-specific
$(\zc,\zs)$ interactions (full schedule in Appendix~\ref{app:schedule}).

\subsection{Inference and Generation}

\paragraph{Clustering.} K-means on deterministic $\muc$, Hungarian-matched
to compute ACC/NMI/ARI; labels are not used.

\paragraph{Naive prior sampling.} $\zc\sim p(\zc\mid y{=}k)$,
$\zs\sim\mathcal{N}(0,I)$. Reliable only when per-class style MMD is used.

\paragraph{Class-conditional style prior (post-hoc).} Without per-class
style MMD, estimate $\bar\mus^{(k)}=\mathbb{E}[\mus\mid y{=}k]$,
$\bar\sigma_s^{2(k)}=\mathrm{Var}[\mus\mid y{=}k]$ from encoded training
data, then sample $\zs\sim\mathcal{N}(\bar\mus^{(k)},\tau^2\diag(\bar\sigma_s^{2(k)}))$
with $\tau=0.25$. This is the second remedy we test, and it requires no
retraining -- only a forward pass over labeled training data to estimate
$\bar\mus^{(k)}$ and $\bar\sigma_s^{2(k)}$.

\section{Case Study Setup}
\label{sec:cifar10-setup}

competent model on its own terms -- otherwise the leakage findings below
would be unsurprising, since a degenerate model could leak trivially. We
report this briefly, as a sanity check rather than a headline result.

\subsection{Experiment 1: Marginal Metrics Hide Leakage}
\label{sec:cross-model}
\label{sec:cross-model-baseline}

\emph{Claim tested:} near-zero global MMD does not imply
$\zs\perp y$, across model families, not just for \ours{}.

We apply the diagnostic of Section~\ref{sec:diagnostics} to four
unsupervised baselines (VAE, WAE-MMD, $\beta$-TCVAE, FactorVAE) and \ours{}
on MNIST. The four baselines are purpose-built for this diagnostic only,
with a lightweight 3-layer convolutional encoder trained for 100 epochs;
they are \emph{not} the same checkpoints as the like-named VAE/WAE-MMD
entries used for CIFAR-10 clustering comparison in
Section~\ref{sec:cifar10-setup}, which follow a different protocol
(Appendix~\ref{app:training}). \ours{}, by contrast, uses its full
ResNet-18 encoder trained for 300 epochs (Section~\ref{sec:instantiation}),
so architecture and training budget are not matched across the five rows of
Table~\ref{tab:cross-model} and the $\Delta_{\mathrm{inter}}$ ranking
between \ours{} and the baselines should not be read as a controlled
comparison. What the mismatch does not undermine is the \emph{within-model}
evidence: for every row individually, global MMD is decoupled from
$\Delta_{\mathrm{inter}}$ and LP regardless of that row's encoder capacity
or training length, which is the comparison the diagnostic actually depends
on.

\emph{Result.} All four baselines show LP far above chance ($74$--$93\%$)
despite near-zero global MMD. WAE-MMD has the largest global MMD among
baselines ($0.0576$, $30$--$300\times$ the others), suggesting its own

$\Delta_{\mathrm{inter}}$ ($9.38$) and LP ($93\%$). $\beta$-TCVAE and
FactorVAE, whose training objectives explicitly penalize latent dependence,
show the smallest $\Delta_{\mathrm{inter}}$ among the five models ($2.30$,
$2.27$) -- but LP stays far above chance ($74$--$76\%$): penalizing total
correlation between latent \emph{dimensions} reduces, but does not

different quantity. \ours{} without the proposed remedy shows the most
extreme leakage of the five ($\Delta_{\mathrm{inter}}=6.27$, LP$=100\%$),

just an elevated statistic.

FactorVAE it is statistically real (LP $74$--$87\%$) but not visually
apparent in a 2D projection -- evidence that a plot is not a substitute for
the quantitative diagnostic.

\subsection{Direct Evidence: The Decoder Causally Uses Leaked Style}
\label{sec:swap}

\emph{Claim tested:} the linear probe of Section~\ref{sec:diagnostics} shows
$\zs$ \emph{contains} recoverable class information; it does not show the
decoder \emph{uses} that information to decide what to generate. We test
this directly with two additional measurements on the same $\delta{=}0$ and
$\delta{=}1$ \ours{} checkpoints as Table~\ref{tab:cross-model}.

\paragraph{The full conditional structure, not just its mean.}
$\Delta_{\mathrm{inter}}$ summarizes class separation as a single
mean-to-mean distance; it says nothing about how far each class conditional
$q(\zs\mid y{=}k)$ itself sits from the prior it is supposed to match. We
compute $\MMD^2(q(\zs\mid y{=}k),\mathcal N(0,I))$ per class and pairwise
$\MMD^2(q(\zs\mid y{=}i),q(\zs\mid y{=}j))$ for all class pairs, on MNIST and
CIFAR-10, at $\delta{=}0$ and $\delta{=}1$. At $\delta{=}0$, mean per-class
MMD is $21\times$ the global MMD on MNIST ($0.0186$ vs.\ $0.00089$) and
$15\times$ on CIFAR-10 ($0.0085$ vs.\ $0.00056$) -- Figure~\ref{fig:cmmd-bar}
makes the point visually: every one of the ten per-class bars sits far above
the global-MMD reference line the marginal regularizer actually optimizes.
At $\delta{=}1$ the gap narrows but does not close (MNIST $4.4\times$;
CIFAR-10 $5.3\times$), the same ``reduces but does not eliminate'' pattern
Experiment 3 reports for $\Delta_{\mathrm{inter}}$ and LP, now shown to hold
for the full per-class MMD, not only its mean-separation proxy.

\begin{figure}[t]
\centering
\includegraphics[width=\linewidth]{conditional_mmd_per_class_bar_mnist.png}
\caption{MNIST, $\delta{=}0$: per-class $\MMD^2(q(\zs\mid y{=}k),\mathcal
         N(0,I))$ (bars) against the global MMD the marginal regularizer
         optimizes (dashed line). Every class sits far above the line the
         model was actually trained to minimize.}
\label{fig:cmmd-bar}
\end{figure}

\paragraph{Latent swap: a causal intervention.}
For every ordered class pair $(a,b)$ we take $\muc$ from a real test image
of class $a$ and $\mus$ from an independently drawn real test image of
class $b$, decode $\mathrm{Dec}(\muc,\mus)$, re-encode the result, and
classify it with the same auxiliary classifier used for self-accuracy
elsewhere. This is a stronger test than naive-prior sampling: it uses only
real, in-distribution encoder outputs, so a failure to recover class $a$
cannot be blamed on an out-of-distribution prior sample -- it can only
reflect what the decoder learned to do with a $(\zc,\zs)$ pair drawn from
two different real images. We report the diagonal-excluded means of
$P(\mathrm{pred}{=}a)$ (content-following) and $P(\mathrm{pred}{=}b)$
(style-following).

\emph{Result.} On MNIST at $\delta{=}0$, off-diagonal content-following is
$0.1\%$ and style-following is $99.2\%$ (Figure~\ref{fig:swap-heatmaps},

in $\zs$, it relies on that information almost exclusively to decide what
to draw, discarding $\zc$ almost entirely off-diagonal. Figure
\ref{fig:swap-grid} shows why: every row (fixed $\zc$) produces visually
identical output regardless of which class donated $\zc$; only the column
(the $\zs$ donor) determines the digit. At $\delta{=}1$, content-following
rises to $60.9\%$ and style-following falls to $18.8\%$ -- a genuine causal
change in what the decoder conditions on, not merely a reduction in a
correlational statistic. On CIFAR-10 the same qualitative flip occurs but
is weaker (content-following $4.2\%\to20.0\%$, style-following
$68.8\%\to38.5\%$; heatmaps and grid in Appendix~\ref{app:tsne},
Figures~\ref{fig:cifar-swap-heatmaps}--\ref{fig:cifar-swap-grid}),
consistent with the cross-dataset asymmetry of Experiment 4 and Experiment
5: CIFAR-10's higher intra-class diversity means the decoder was never as
exclusively dependent on $\zs$ for identity to begin with, so there is
proportionally less for the remedy to undo. The pairwise conditional-MMD
structure behind Figure~\ref{fig:cmmd-bar}'s per-class bars, for both
datasets, is likewise in Appendix~\ref{app:tsne}
(Figure~\ref{fig:cmmd-pairwise}).

\subsection{Experiment 3: Per-Class MMD Reduces but Does Not Eliminate Leakage}
\label{sec:exp3}

\emph{Claim tested:} the remedy of Section~\ref{sec:general-remedy} works in
the direction intended, but does not drive leakage to zero, and reaching
$100\%$ self-accuracy requires combining it with the post-hoc prior.

\emph{Result.} From Table~\ref{tab:cross-model}, per-class style MMD cuts
\ours{}'s $\Delta_{\mathrm{inter}}$ by $77\%$ ($6.27\to1.46$) and LP by $54$
points ($100\%\to45.6\%$) -- still far above the $10\%$ chance rate, and
higher than three of the four unsupervised baselines in the same table.
Naive-sampling self-accuracy rises from $0.15$ to $0.70$, not $1.00$: the
remedy reduces how much class information $\zs$ carries, but a linear probe
can still recover the label well above chance, and naive sampling still
fails on roughly $3$ in $10$ generations. Reaching $100\%$ requires
\emph{combining} both remedies: applying the post-hoc class-conditional
prior ($\tau{=}0.25$, Section~\ref{sec:sampling}) on top of the $\delta{=}1$
checkpoint, rather than relying on either alone, which we verified directly
on this checkpoint (naive $0.70\to$ class-conditional $1.00$, same protocol
as Table~\ref{tab:sampling}). We read the two remedies as complementary
rather than redundant: per-class style MMD reduces how much class
information $\zs$ carries, and the post-hoc prior corrects for what
remains.

\paragraph{Why does combining remedies still work at $\delta{=}1$?} The
class-conditional sampling strategies above are themselves fit to per-class
statistics of $\zs$, so it is natural to ask whether they remain
distinguishable once $\delta{=}1$ has pulled every $q(\zs\mid y{=}k)$ toward
$\mathcal N(0,I)$. We test this in latent space alone, with no decoding: an
independent linear probe trained on real $\zs$ (held-out accuracy $98.7\%$
at $\delta{=}0$, only $32.3\%$ at $\delta{=}1$, consistent with the LP drop
above) is asked to classify synthetic $\zs$ draws from each sampling
strategy. At $\delta{=}0$ every class-conditional strategy is $\geq99.8\%$
self-consistent by this measure. At $\delta{=}1$, consistency collapses:
the class-mean strategy falls to $80.0\%$ and the genuinely-distributional
strategies ($\tau{=}0.25$, $\tau{=}0.50$, empirical bank) fall to
$15$--$28\%$ -- \emph{lower} than at $\delta{=}0$, even though decoder
self-accuracy under the same strategies reaches $100\%$ (verified above).
The resolution is Section~\ref{sec:swap}'s causal intervention: at
$\delta{=}1$ the decoder has shifted toward reading identity off $\zc$
rather than $\zs$ (content-following $0.1\%\to60.9\%$), so the specific
$\zs$ value supplied at generation time matters less than it did at
$\delta{=}0$. Combining remedies reaches $100\%$ self-accuracy not because
the sampled $\zs$ becomes more class-distinguishable in latent space -- by
this measure it becomes \emph{less} distinguishable -- but because the
decoder itself has become less sensitive to which $\zs$ it receives.

\subsection{Experiment 4: Leakage Tracks Intra-Class Diversity, Self-Accuracy Does Not}
\label{sec:exp4}
\label{sec:cross-dataset}

\emph{Claim tested:} Section~\ref{sec:mechanism} predicts leakage severity
should track intra-class visual diversity: MNIST (least diverse) $>$
Fashion-MNIST $>$ CIFAR-10 (most diverse). We test this on the $\delta{=}0$
\ours{} checkpoint for all three datasets, using the same diagnostic
throughout.

\begin{figure}[t]
\centering
\includegraphics[width=\linewidth]{crossdataset_leakage.png}
\caption{Left: $\Delta_{\mathrm{inter}}$ and linear-probe accuracy across
         datasets, ordered by increasing intra-class visual diversity---both
         decrease monotonically, matching the hypothesis. Right: naive-Gaussian
         generation self-accuracy does \emph{not} follow the same order
         (CIFAR-10 is lowest, not highest); see text.}
\label{fig:crossdataset}
\end{figure}

\emph{Result.} $\Delta_{\mathrm{inter}}$ and LP support the hypothesis
cleanly: MNIST ($6.27$, $100.0\%$) $>$ Fashion-MNIST ($4.86$, $97.7\%$) $>$
CIFAR-10 ($4.19$, $89.9\%$). Naive-Gaussian generation self-accuracy does
not: MNIST $0.15$, Fashion-MNIST $0.17$, CIFAR-10 $0.12$ -- CIFAR-10 is
lowest, not highest. The two families of metrics differ in what they are
computed on, and that difference explains the disagreement rather than
undermining either measurement. $\Delta_{\mathrm{inter}}$ and LP operate
directly on $\zs$ and therefore isolate the dependency we care about.
Self-accuracy is measured on the generated \emph{image}, mediated by an
auxiliary classifier, so it additionally inherits how confusable the real
classes already are under blurry generation -- a dataset-difficulty effect
with nothing to do with conditional style leakage, and one that CIFAR-10
has on top of leakage. We see no principled reason to discard the metric
that disagrees, and doing so would let us report a cleaner story than the
data supports; the disagreement instead tells us that generation
self-accuracy, on its own, is not a reliable cross-dataset proxy for
leakage severity, even though it remains the right metric for asking
whether a specific checkpoint's generation is repaired
(Section~\ref{sec:sampling}).

all sit at $99$--$99.4\%$, statistically indistinguishable from $\delta{=}0$,
and $\delta{=}1$ is the \emph{only} point with a large drop; on CIFAR-10,
$\delta\in\{0,0.03,0.1,1,3\}$ all sit at $80$--$81\%$, and $\delta{=}0.3$ is
the only point with a large drop ($71.5\%$). We ran one seed per $\delta$,
so we cannot separate a genuine non-monotonic effect of $\delta$ on
clustering from this particular run's initialization at that one point;
resolving that would require repeating each $\delta$ across multiple seeds,
which is beyond this draft's compute budget (Section~\ref{sec:limitations}).
What the sweep does establish, which the two-point comparison could not, is
directional: leakage reduction is a smooth function of $\delta$ on this
evidence, while clustering accuracy is not, and neither dataset shows a
clean monotonic trade-off curve between the two at a single seed per point.
The original interpretation -- that the endpoint cost tracks how much a
dataset's model depended on the leak -- remains consistent with the
$\delta{=}0$-vs-$\delta{=}1$ comparison it was based on, but should not be
read as describing a smooth relationship across $\delta$, which this sweep
shows does not hold.

% ============================================================
\section{Discussion}
\label{sec:discussion}
% ============================================================

\paragraph{Why CIFAR-10 is milder than MNIST, with a caveat.}
CIFAR-10's higher intra-class visual diversity weakens conditional style
dependence, and $\Delta_{\mathrm{inter}}$/LP confirm this cleanly
(Experiment 4). But Experiment 5 shows the practical remedy does not
inherit this cleanly: the class-conditional Gaussian prior that perfectly
fixes MNIST generation only partially fixes CIFAR-10 generation, and
CIFAR-10 samples remain visibly blurry (FID $\sim\!83$--$84$, well above
photorealistic ranges). We avoid describing CIFAR-10 naive-sampling output
as ``visually plausible''; at this FID the more accurate description is
``recognizable but not sharp,'' and under the $\tau{=}0.25$
class-conditional prior several classes are not reliably identifiable by
eye despite scoring well on the auxiliary classifier
(Figure~\ref{fig:cifar-sampling-grid}).

\paragraph{Global vs.\ conditional regularization.}
Global aggregate matching is standard in WAEs and disentanglement models;
our results show it is insufficient whenever the style variable must be
class-invariant for generation. Per-class style MMD is a supervised
analogue of total correlation penalties, targeting the single dependency
$\zs\not\perp y$ directly rather than dependence among latent dimensions in
general.

\paragraph{The reconstruction--generation gap.}
The MNIST checkpoint reaches SSIM $0.983$ yet FID $73.99$ under naive prior
sampling (Figure~\ref{fig:recon-vs-gen}). Reconstruction quality measures
fidelity on the posterior manifold, not the prior; evaluation of generative
clustering models should report both, since Section~\ref{sec:cross-model-baseline}
shows the two can diverge arbitrarily.

\subsection{Limitations}
\label{sec:limitations}

We list what this paper does \emph{not} establish, rather than leave it
implicit; several of these are previewed in the Scope paragraph of
Section~\ref{sec:intro} and restated here in full. (1) Baseline comparisons
(Table~\ref{tab:cifar-main}) are single-seed; we do not report multi-seed
variance we have not measured, and the CIFAR-10 comparison is not a
superiority claim for \ours{} over the baselines, only evidence that it is
not a degenerate model. (2) The clustering-leakage trade-off
(Table~\ref{tab:tradeoff}, Figure~\ref{fig:tradeoff}) now spans six $\delta$
values per dataset rather than two, but each is a single training run; the
non-monotonic ACC pattern we observe (Section~\ref{sec:tradeoff}) may
reflect true $\delta$-dependent instability at specific values or ordinary
seed variance we cannot distinguish without repeating each $\delta$ across
multiple seeds, which we have not done. (3) The cross-model
comparison (Experiment 1) does not control for encoder capacity or training
budget between \ours{} and the four baselines. (4) Per-class style MMD is a
supervised, label-guided regularizer; we do not report a component-wise
ablation of \ours{} beyond the $\delta$ axis (e.g., removing the semantic
variable, the class MMD term, or varying the prior geometry), since we do
not have completed runs for those variants. (5) Generation self-accuracy is
confounded by dataset-intrinsic classification difficulty and should not be
used alone as a cross-dataset leakage-severity proxy (Experiment 4). (6)
The class-conditional style prior's failure to fully transfer to CIFAR-10
(Experiment 5) is measured on one checkpoint per dataset; we have not
tested whether a richer conditional (e.g., a per-class mixture rather than
a single Gaussian) closes the gap.

% ============================================================
\section{Conclusion}
% ============================================================

Conditional style leakage is a failure mode in factorized generative
models: global aggregate regularization of a style variable does not
prevent it from becoming class-dependent, because marginal matching is
compatible with $\zs$ being maximally informative about the class label,
not just weakly correlated with it (Proposition~\ref{prop:marginal-not-sufficient}).
We measured this gap with a diagnostic across five model families and
showed it is statistically real even when not visually obvious. A causal
latent-swap intervention confirms the decoder does not merely have access
to the leaked information but measurably conditions on it (off-diagonal
content-following rises from $0.1\%$ to $60.9\%$ on MNIST once the remedy
is applied). Per-class style MMD cuts inter-class style separation by
$67$--$77\%$ at the originally-measured $\delta{=}1$ and, across a fuller
six-point $\delta$ sweep, reduces it smoothly on both datasets; the
clustering cost is dataset-dependent and, at a single seed per $\delta$,
noisier than the original two-point comparison suggested -- small across
most of the sweep on both datasets, with one large outlier per dataset we
cannot yet attribute to $\delta$ itself rather than seed variance. Per-class
style MMD also raises MNIST naive-sampling self-accuracy from $15\%$ to
$70\%$ ($100\%$ combined with the post-hoc style prior). Critically, the remedy
that fully repairs MNIST generation only partially repairs CIFAR-10
generation, so fixing the diagnostic finding on one dataset does not
automatically fix the underlying generative gap on another. Factorized
generative models should verify class-invariance of style variables via
conditional diagnostics, not marginal statistics alone, and should report
where proposed remedies do and do not generalize rather than presenting a
single-dataset result as general.

\section{Architecture Details}
\label{app:arch}

The semantic head produces $(\tilde\muc,r_c)$, giving
$\muc=\tilde\muc/\|\tilde\muc\|_2$ and concentration
$\rho_c=\sigma(r_c)(1-\varepsilon)$; the semantic latent is sampled by the
Spherical Cauchy M\"obius reparameterization $\eta_c\sim\mathrm{Unif}(\Sph^{d_c-1})$,
$\zc=T_{\muc,\rho_c}(\eta_c)$. The style head produces $(\mus,\log\sigma_s^2)$
and $\zs=\mus+\sigma_s\odot\varepsilon_s$, $\varepsilon_s\sim\mathcal N(0,I)$.
The ResNet-18 backbone for $32\times32$ inputs replaces the first
$7\times7$ convolution (stride 2) with a $3\times3$ convolution (stride 1,
padding 1) and removes the max-pool layer, yielding a $4\times4$ spatial
output with 512 channels; a shared FC layer maps
$512\times4\times4{=}8{,}192$ to 256 dimensions with SiLU, from which
separate linear heads produce the semantic and style parameters. The
decoder concatenates $[\zc;\zs]$ ($d_c{=}64$, $d_s{=}128$ in all
experiments) and maps it through three ResBlockUp stages (bilinear
$2\times$ upsample, $1\times1$ projection, GroupNorm+SiLU+Conv residual
block; $512{\to}256{\to}128{\to}64$ channels, $4\times4\to32\times32$),
followed by a $3\times3$ output convolution and sigmoid. For each class
$k$, \ours{} maintains a center $m_k\in\Sph^{d_c-1}$ with prior
$p(\zc\mid y{=}k)=\SCauchy(m_k,\rho_p)$, $\rho_p{=}0.7$, updated by EMA from
batch class-mean directions once per epoch,
$m_k\leftarrow\mathrm{normalize}(\tau m_k+(1-\tau)\bar\muc^{(k)})$,
$\tau{=}0.95$. The full training objective is
\begin{align}
  \mathcal{L} &= \mathcal{L}_{\mathrm{rec}} + \alpha(t)\mathcal{L}_{\mathrm{class}}
   + \beta(t)\mathcal{L}_{\mathrm{agg}} + \gamma(t)\mathcal{L}_{\mathrm{style}} \nonumber\\
  &\quad + \delta(t)\mathcal{L}_{\mathrm{style\text{-}cls}} + \eta(t)\mathcal{L}_{\mathrm{cls}},
\end{align}
with $\mathcal{L}_{\mathrm{rec}}=\lambda_1\|x-\hat x\|_1+\lambda_{\mathrm{LPIPS}}\mathrm{LPIPS}(x,\hat x)$,
$\mathcal{L}_{\mathrm{class}}=\frac1K\sum_k\MMD^2(Q_k,P_k)$ with
$Q_k=\{\zc^i{:}y_i{=}k\}$, $P_k\sim p(\zc\mid y{=}k)$,
$\mathcal{L}_{\mathrm{agg}}=\MMD^2(\{\zc^i\},\{z_{c,r_j}^p\})$ against a
random-class prior mixture, and $\mathcal{L}_{\mathrm{cls}}=\CE(h(\muc),y)$
a linear auxiliary classifier preventing semantic collapse.

\section{Smooth Construction Motivating $\Delta_{\mathrm{inter}}$}
\label{app:proof}

Proposition~\ref{prop:marginal-not-sufficient} uses an adversarial
partition construction to establish the impossibility result in its
strongest, cleanest form. The following construction is not a stronger
proof -- it is a smoother, more empirically representative special case,
included because it connects the same impossibility to the
$\Delta_{\mathrm{inter}}$ statistic used as a diagnostic throughout the
paper.

Let $K{=}10$, $d_s{=}2$, and define class-conditional distributions
$q(\zs\mid y{=}k)=\mathcal N(\mu_k,\Sigma_k)$ with
$\mu_k=r(\cos(2\pi k/K),\sin(2\pi k/K))^\top$ for radius $r{>}0$ and
$\Sigma_k=I-\frac{r^2}{1+r^2}\hat\mu_k\hat\mu_k^\top$,
$\hat\mu_k=\mu_k/\|\mu_k\|$ -- a smooth family of Gaussian conditionals with
class-specific means arranged on a circle, unlike the disjoint-support
partition of the main-text proposition. The mixture mean is
$\frac1K\sum_k\mu_k=0$ and the mixture covariance is
$I+\frac{r^2}{K}\sum_k\hat\mu_k\hat\mu_k^\top-\frac{r^2}{K}I$, which
approaches $I$ for this symmetric configuration. The inter-class mean
separation is $\Delta_{\mathrm{inter}}\approx r\sqrt2$, unbounded as
$r\to\infty$, while the marginal stays $\approx\mathcal N(0,I)$: as $r$
grows, this smooth, mean-separated construction drives
$\Delta_{\mathrm{inter}}$ to arbitrarily large values under an
approximately matched marginal, illustrating in the same geometry as our
empirical statistic why $\Delta_{\mathrm{inter}}$ is worth tracking even
though, unlike Proposition~\ref{prop:marginal-not-sufficient}, this
particular construction only becomes exact in the $r\to\infty$ limit.
