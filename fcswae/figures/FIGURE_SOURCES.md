## Independent external latent-swap summary (added 2026-08)

- `external_swap_summary.png`
  - Source results: `runs_diag/latent_swap/{mnist,cifar10}_delta{0,1}_external_n500/results.json`
  - Aggregate: `runs_diag/latent_swap/external_swap_summary.json`
  - Evaluator: independent real-image pixel classifier
  - Protocol: 500 draws per ordered class pair; deterministic posterior-mean
    swap; 95% percentile bootstrap over 90 off-diagonal class pairs

Generated by:

```bash
.venv/bin/python scripts/plot_external_swap_summary.py \
  --mnist-baseline runs_diag/latent_swap/mnist_delta0_external_n500/results.json \
  --mnist-remedy runs_diag/latent_swap/mnist_delta1_external_n500/results.json \
  --cifar-baseline runs_diag/latent_swap/cifar10_delta0_external_n500/results.json \
  --cifar-remedy runs_diag/latent_swap/cifar10_delta1_external_n500/results.json \
  --figure-out fcswae/figures/external_swap_summary.png \
  --json-out runs_diag/latent_swap/external_swap_summary.json --seed 0
```
