## 1. Bối cảnh

Lần chạy đầu tiên (24/06) gặp hai vấn đề nghiêm trọng:

1. **NaN ngay epoch 1** — do `logvar_s` khởi tạo ngẫu nhiên → overflow khi sampling `z_s`.
2. **Loss explosion từ epoch ~52** (Phase B) — `L_var = -Var(z_s)` không bị chặn, gradient kéo variance `z_s` → ∞; StyleMMD dùng median-heuristic bandwidth bị saturate nên không counterbalance được.

Sau các fix, chạy lại **3 seeds** (0, 1, 2) qua script `/tmp/run_f_cs_wae.sh` với `.venv/bin/python3` trên `cuda:1`, hoàn thành lúc **09:08** ngày 25/06.

## 2. Những gì đã sửa / thêm

### 2.1 Fix NaN (lần chạy đầu)

| File | Thay đổi |
|------|----------|
| `src/models/f_cs_wae.py` | Khởi tạo `fc_logvar_s` về 0; `logvar_s.clamp(-10, 10)` trước `exp` |
| `src/models/f_cs_wae_ablation.py` | Tương tự cho ablation encoder |

**Hiệu quả:** Training không còn NaN ngay epoch 1; reconstruction loss giảm bình thường trong Phase A.

### 2.2 Fix loss explosion (lần chạy thứ hai — fix chính)

| File | Thay đổi | Lý do |
|------|----------|-------|
| `src/config_f_cs_wae.py` | `lambda_var: 0.01 → 0.0` | `L_var` khuyến khích variance không giới hạn; StyleMMD đã đủ để regularize `z_s` |
| `src/utils/loss_f_cs_wae.py` | StyleMMD: median-heuristic → **multi-scale RBF** `[0.5, 1, 2, 5, 10, 20, 50]` | Khi `z_s` spread rộng, median bandwidth → kernel ≈ 0, MMD mất tác dụng |
| `src/trainers/trainer_f_cs_wae.py` | `lv = cfg.lambda_var if gamma > 0 else 0.0` | Đảm bảo `L_var` không active trong Phase A |

### 2.3 Kết quả training history (seed 0) — trước vs sau fix

| Epoch | Run cũ (broken) `Total` | Run mới (fixed) `Total` | Run mới `Var(z_s)` |
|-------|-------------------------|-------------------------|---------------------|
| 50 | 0.0638 | 0.0633 | Var ≈ 28 (chưa regularize) |
| 60 | **-6.8×10¹⁴** | 0.0778 | Var ≈ 1.34 |
| 100 | **-5.2×10¹⁸** | 0.0836 | Var ≈ 1.07 |
| 300 | **-1.2×10²¹** | 0.2361 | Var ≈ 1.03 |

Run mới: loss ổn định suốt 300 epochs; `Var(z_s) ≈ 1` từ epoch 60 trở đi (gần N(0,I)).

## 8. Kết luận

1. **Root cause chính** của run đầu: `L_var` không bounded + StyleMMD median-heuristic fail khi `z_s` variance lớn.
2. **Fix tối thiểu và đủ:** `lambda_var=0` + multi-scale StyleMMD; giữ init/clamp `logvar_s`.
3. **Kết quả sau fix** ổn định và mạnh: ACC ~81%, FID ~83, SSIM ~0.70 — sẵn sàng đưa vào bảng chính của paper.
4. **Bước tiếp theo:** chạy extended baselines và ablation để hoàn thiện phần so sánh và phân tích component.
