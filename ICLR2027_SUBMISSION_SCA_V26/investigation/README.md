# Investigation and audit supplement

The supplementary ZIP contains the proofs, fixed audit protocol, raw traceable
artifacts, source snapshots, and internal content manifest used by SCA v26.  Its
anonymity report records zero findings and verifies every internal manifest entry.

The exploratory UTKFace continuous-age pilot is intentionally absent.  It was
run after this evidence boundary and produced a variance pathology; it is not a
paper result and must not be uploaded as support for the manuscript claims.

Untraceable external five-pair and FACT-Lite aggregates are also excluded.  The
archive contains no datasets or model checkpoints.
